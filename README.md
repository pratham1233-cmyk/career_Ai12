📌 About the Project

CareerAI is an intelligent career development platform designed to bridge the gap between students' skills and industry requirements. It uses AI-powered analysis and personalized recommendations to help students make better career decisions, improve their skills, prepare for recruitment, and explore job opportunities.

The platform also provides recruiters with tools to discover suitable candidates based on their profiles, skills, and career readiness.

---

❓ Problem Statement

Students often struggle to identify the right career path, understand industry-required skills, find relevant learning resources, and prepare for placements. Recruiters also spend considerable time identifying candidates with suitable skills and qualifications.

CareerAI aims to solve these challenges through a unified platform that combines AI-based career guidance, resume analysis, coding practice, skill development, and candidate discovery.

⚙️ How CareerAI Works

1. Students create their profile and provide their skills, education, and career interests.
2. CareerAI analyzes their information and career goals.
3. AI generates personalized career recommendations and identifies skill gaps.
4. Students receive relevant roadmaps, coding practice, and learning suggestions.
5. Students track their progress and explore industry opportunities.
6. Recruiters can discover and evaluate suitable candidates through the platform.

🚀 Installation & Setup

Prerequisites

- Node.js
- npm
- Git
- Firebase configuration
- AI API credentials (if required)

1. Clone the Repository

git clone https://github.com/Pratham1233-cmyk/career_Ai12.git

2. Navigate to the Project

cd career_Ai12

3. Install Dependencies

npm install

4. Configure Environment Variables

Create a ".env.local" file in the root directory and add your required Firebase and AI configuration variables.

# Add your environment variables here

«Never upload private API keys, credentials, or secret environment variables to GitHub.»

5. Start the Development Server

npm run dev

Open your browser and visit:
